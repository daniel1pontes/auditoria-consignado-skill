# Execução

O pacote inclui `core/`, independente de serviços de IA. Python 3.11+, PyMuPDF, openpyxl, Pillow e ReportLab são necessários; a presença e instalação de dependências no ambiente do ChatGPT não são garantidas. Não instale nem envie dados a provedores sem conhecimento do usuário. Em um ambiente local controlado consulte o README do repositório para instalação e esquema do caso. Execute a partir da pasta da skill: `python -m core.cli extrair arquivo.pdf -o extracao.json` e `python -m core.cli relatorio caso.json -o relatorio.pdf`. O JSON extraído contém dados pessoais quando presentes: trate-o como documento sensível. A consulta BCB é opcional e envia apenas código de série e intervalo de datas ao BCB. Nenhuma operação de acesso ao Meu INSS é automatizada pelos scripts.
